คู่มือแนะนำเมนูเบื้องต้น

1. หน้าหลัก (Dashboard)
แสดงข้อมูลพื้นฐานของคอมพิวเตอร์ เช่น CPU, RAM และพื้นที่จัดเก็บข้อมูล เพื่อให้ตรวจสอบภาพรวมของเครื่องได้ง่ายขึ้น

2. Storage Analyzer
ตรวจสอบพื้นที่จัดเก็บข้อมูลในไดรฟ์และโฟลเดอร์ต่าง ๆ ช่วยค้นหาว่าโฟลเดอร์ไหนใช้พื้นที่มาก เพื่อให้รู้ว่าควรตรวจสอบไฟล์ส่วนใดก่อน

3. Large File Finder
ค้นหาไฟล์ขนาดใหญ่ พร้อมแสดงชื่อไฟล์ ขนาด และตำแหน่งจัดเก็บ ช่วยให้ตรวจสอบไฟล์ที่ใช้พื้นที่มากก่อนตัดสินใจลบ

4. Smart Cleanup
ตรวจสอบไฟล์ชั่วคราวที่อาจไม่จำเป็น และให้ผู้ใช้เลือกไฟล์ที่ต้องการลบ เพื่อช่วยเพิ่มพื้นที่ว่างในเครื่อง ควรตรวจสอบรายการก่อนลบทุกครั้ง

5. PC Health Check
ตรวจสอบข้อมูลและสถานะพื้นฐานของคอมพิวเตอร์ ช่วยให้ผู้ใช้เห็นข้อมูลสำคัญของเครื่องและเริ่มตรวจสอบปัญหาเบื้องต้นได้ง่ายขึ้น

6. PDF Tools
รวมเครื่องมือจัดการไฟล์ PDF เช่น
- Merge PDF: รวมไฟล์ PDF
- Split PDF: แยกหน้า PDF
- จัดเรียงหน้า: เปลี่ยนลำดับหน้าเอกสาร
- Rotate PDF: หมุนหน้าเอกสาร
- Delete Pages: ลบหน้าที่ไม่ต้องการ
- Images to PDF: รวมรูปภาพเป็นไฟล์ PDF
- PDF to Images: แปลงหน้า PDF เป็นรูปภาพ
- PDF Compressor: บีบอัดไฟล์ PDF เพื่อลดขนาดไฟล์

7. Windows Tools
รวมเครื่องมือช่วยตรวจสอบและจัดการ Windows เบื้องต้น เช่น
- Startup: ดูรายการโปรแกรมที่เริ่มทำงานพร้อม Windows
- Battery Report: สร้างรายงานข้อมูลแบตเตอรี่
- SFC Verify: ตรวจสอบไฟล์ระบบ Windows
- DISM CheckHealth: ตรวจสอบสถานะ Component Store ของ Windows
