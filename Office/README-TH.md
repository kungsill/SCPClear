# SCP Office — ชุดโปรแกรมสำนักงานภาษาไทยสำหรับงานราชการ

รวมซอร์สโค้ดทั้งหมดไว้ที่เดียวเพื่อแก้ไขต่อ ต้นทางคือโอเพนซอร์สของ [storytold](https://github.com/storytold) (ArtCraft)
สัญญาอนุญาต MIT หรือ Apache-2.0 ใช้ แก้ไข และแจกจ่ายต่อได้ ต้องเก็บไฟล์ LICENSE และ NOTICE ไว้

## โฟลเดอร์

| โฟลเดอร์ | คืออะไร | ขนาด |
|---|---|---|
| `wordcraft/` | โปรแกรมแบบ Word (.docx .doc .rtf .odt ส่งออก PDF) **ฉบับภาษาไทยอยู่ที่นี่** | ~50 MB |
| `gridcraft/` | โปรแกรมแบบ Excel | ~19 MB |
| `deckcraft/` | โปรแกรมแบบ PowerPoint | ~21 MB |
| `pdfcraft/` | อ่าน/แก้ไข PDF | ~79 MB |
| `craft-libs/`, `craft-fonts/` | ไลบรารีร่วม ฟอนต์โอเพนซอร์ส (รวม Noto Sans Thai) | ~100 MB |

`gridcraft` `deckcraft` `pdfcraft` ยังเป็นภาษาอังกฤษ ยังไม่ได้แปลหรือทดสอบภาษาไทย

## สิ่งที่แก้เพิ่มใน wordcraft (ฉบับ SCP)

1. **เมนูภาษาไทยทั้งหมด** `crates/ui-egui/src/i18n/th.tsv` 2,649 ข้อความ (ที่เหลืออีก 25 เหมือนภาษาอังกฤษอยู่แล้ว เช่น ขนาดกระดาษ) ลงทะเบียนใน `i18n/mod.rs` เลือกได้ที่ ไฟล์ › ตัวเลือก › ภาษาของหน้าจอโปรแกรม หรือใช้ตามภาษา Windows อัตโนมัติ
   แปลจากความหมายของข้อความภาษาอังกฤษ ตามกติกาของโปรเจกต์ (clean room: ไม่คัดลอกจากเมนูของ Microsoft)
2. **ฟอนต์ไทยในเมนู** ฝัง Sarabun (SIL OFL) ใน `assets/fonts/` และ `theme.rs` เพราะฟอนต์เมนูเดิม (Inter) ไม่มีอักษรไทย
3. **ตัดบรรทัดภาษาไทยด้วยพจนานุกรม** `crates/layout/src/thai.rs` ใช้ ICU4X (Unicode Consortium) หาขอบเขตคำ ไม่ต้องเว้นวรรคระหว่างคำก็ขึ้นบรรทัดใหม่ถูก ต้นทางตัดได้เฉพาะที่ช่องว่าง มีเทสต์ 4 ข้อ

## สร้างโปรแกรม

ต้องมี Rust (cargo 1.95 ขึ้นไป) ดับเบิลคลิก `BUILD-OFFICE.bat` ได้ไฟล์ `dist\WordCraft-TH.exe` (สร้างครั้งแรกใช้เวลาราว 10 นาที ครั้งต่อไปไม่กี่นาที)

ทดสอบ: `cd wordcraft` แล้ว `cargo test -p wordcraft-layout thai` และ `cargo test -p wordcraft-ui-egui i18n`

## ยังไม่ได้ทำ (ตามลำดับที่แนะนำ)

1. ทดสอบกับไฟล์ `.docx` จริงของหน่วยงาน (โดยเฉพาะไฟล์ที่บันทึกจาก WPS) และตรวจว่าสระ/วรรณยุกต์ซ้อนถูกต้องทั้งบนหน้ากระดาษและในเมนู
2. แม่แบบหนังสือราชการตามระเบียบงานสารบรรณ (บันทึกข้อความ หนังสือภายนอก/ภายใน ตราครุฑ TH Sarabun PSK 16 pt ระยะขอบตามระเบียบ)
3. ตัดคำภาษาไทยเมื่อคลิกสองครั้งเลือกคำ และเมื่อกด Ctrl+ลูกศร
4. ตรวจการสะกดคำไทย (ต้องมีพจนานุกรม) และการจัดแนวกระจายแบบไทย
5. แปลโปรแกรมพี่น้อง (gridcraft deckcraft pdfcraft) โดยใช้วิธีเดียวกัน
6. ส่งไฟล์ติดตั้งไปเครื่องพยาบาลด้วย SCP-Remote ("ส่งโปรแกรม" แบบเดียวกับ SCPclear) และใส่เป็นเมนูใน SCPclear

## ข้อควรระวัง

- โปรเจกต์ต้นทางเขียนไว้เองว่ายังเป็น alpha ประเมินว่าพร้อมใช้งานจริงราว 60% อย่าใช้กับเอกสารสำคัญหรือข้อมูลผู้ป่วยจนกว่าจะทดสอบเสร็จ และเก็บต้นฉบับ `.docx` เดิมไว้เสมอ
- ซอร์สนี้ดึงมาเมื่อ 20 ต.ค. 2569 ถ้าจะอัปเดตตามต้นทางให้ใช้ `git pull` ในแต่ละโฟลเดอร์ แล้วตรวจว่าการแก้ของเราที่ระบุข้างบนยังอยู่

## เรื่องเครื่องหมายการค้า ArtCraft

ชื่อ โลโก้ และเครื่องหมายของ ArtCraft **ไม่ได้อยู่ใต้สัญญาโอเพนซอร์ส** (ดู `docs/brand/LICENSE-brand.txt` ในแต่ละโฟลเดอร์) และสัญญากำหนดว่าฉบับที่แก้ไขแล้วที่เผยแพร่ต้องไม่มีเครื่องหมายเหล่านี้ ดังนั้นใน repo นี้:

- ลบไฟล์โลโก้ ArtCraft (`docs/brand/*.png|svg`) ออกจากทุกโปรเจกต์แล้ว เหลือเฉพาะไฟล์สัญญา
- ไม่รวม `craft-launcher` (ตัวเปิดโปรแกรมของ ArtCraft ที่ใช้เครื่องหมายเหล่านั้นเป็นหลัก)
- ฉบับของเราไม่ใช่ผลิตภัณฑ์ของ ArtCraft และไม่ได้รับการรับรองจากทีม ArtCraft: ใช้ชื่อ **SCP Office** เป็นชื่อเรียก และระบุเป็นข้อความธรรมดาได้ว่า "พัฒนาต่อจาก WordCraft ของทีม ArtCraft"
- ภาพในไฟล์ README ของต้นทางที่อ้างโลโก้เหล่านี้จะแสดงไม่ขึ้น ซึ่งเป็นเรื่องปกติ
